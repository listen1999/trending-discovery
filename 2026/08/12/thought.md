### 信号 #1：AI 公司引以为傲的"加密思维链"，被证明可以被跨模型破解

主信源：@kotekjedi_ml（亚历山大·潘菲洛夫 Alexander Panfilov，论文第一作者，图宾根 ELLIS 人工智能研究所 / 马克斯·普朗克智能系统研究所研究者）
转发扩散：@yaringal（雅林·加尔，牛津大学机器学习教授，OATML 研究组负责人，英国 AI 安全研究院 AISI 专家顾问）· @paulg（保罗·格雷厄姆，Y Combinator 创始人）· 约 1-5 小时前
佐证：arXiv 论文 2608.09867 · Hugging Face Papers · AI Weekly 等技术媒体报道（均经 web_search 核实）
题材分类：科技（AI 安全）

故事 / 场景：
"我们终于可以聊这件事了。"潘菲洛夫团队今天发布的推文这样开头。他们发现，OpenAI、Anthropic、Google 等公司为了防止模型的"思考过程"（reasoning，即模型在给出最终答案前的内部推理步骤）被竞争对手蒸馏或窃取，把这段过程加密后打包传给客户端——但这些加密块在同一家公司旗下的不同模型、不同用户、不同会话之间居然是可以互相通用的。研究者把一个从强模型那里截获的加密推理块，塞进同一公司防护更弱的模型里，后者就会老老实实把它解密成明文——相当于把一台防护松懈的机器，变成了破解另一台高度设防机器的"解密预言机"（decryption oracle，指被攻击者当作现成解密工具来用的另一个系统）。团队从 GitHub 和 Hugging Face 上公开的 6708 条 AI 智能体（agent，指能自主拆解任务、调用工具完成多步操作的 AI 程序）执行记录里，解码出 31.5 万个可读的推理块，里面翻出了 62 个 API 密钥、33 个密码、24 个访问令牌和 30 个个人邮箱地址（来源：论文摘要及 Hugging Face 论文页，经 web_search 核实）。

为什么值得思考：
这不是一次"从天而降"的发现——经 web_search 核实，独立研究者今年 5、6 月就报告过同样的漏洞，但 OpenAI 当时称报告"无法复现"，Anthropic 表示"看不到安全含义"，最多考虑在开发者文档里加一句提醒。今天这篇论文用真实泄露的密钥和密码证明，被轻描淡写的问题已经在生产环境里造成实际损失。更值得琢磨的是这场"回旋镖"：三大公司此前为了堵住"思维链明文泄露"这个漏洞，把推理过程加密——而正是这个加密设计的"跨模型互通"特性，制造出了一个新的、影响范围更大的漏洞。

关键引文（如有则中英并存）：

>
> 中：我们找到了一种方法，利用每一家前沿 AI 公司 API 里的一个漏洞，提取出模型被隐藏的推理过程。

## 六、TOP 3 深度挖掘

#### 深挖：AI 公司的"加密思维链"被证明可跨模型破解

事实核实：
经 web_search 核实，论文《Stealing Reasoning Traces from Proprietary LLM APIs》（arXiv 2608.09867）于 2026 年 8 月 10 日提交，作者为亚历山大·潘菲洛夫（Alexander Panfilov）、大卫·施莫茨（David Schmotz）、伊利亚·舒迈洛夫（Ilia Shumailov）等 8 人，来自图宾根 ELLIS 人工智能研究所与马克斯·普朗克智能系统研究所。论文证明，加密推理块在同一提供商的不同会话、不同用户、不同模型之间可以互相通用——攻击者把从防护更强的模型那里截获的加密块，塞进防护更弱的模型里当"解密预言机"使用。团队从 GitHub、Hugging Face 上公开的 6708 条 AI 智能体执行记录中，成功解码出 31.5 万个推理块，其中含 62 个 API 密钥、33 个密码、24 个访问令牌、30 个个人邮箱地址。另有技术媒体报道给出"367 个个人隐私信息、182 个凭证"的统计口径，两种统计口径在具体分类标准上略有出入[未经多源验证具体分类细节，但两者量级一致，均指向数十万条被解码推理内容中存在大量真实敏感信息]。经 web_search 核实，OpenAI、Anthropic、Google 三家公司此后均已弃用明文推理传输方式。

思想溯源：
这不是一个全新的问题类型——"通过 API 查询窃取模型能力"这一研究方向，最早可追溯到 2016 年弗洛里安·特拉梅尔（Florian Tramèr）等人在 USENIX Security 会议上发表的《Stealing Machine Learning Models via Prediction APIs》，该论文首次系统证明可以通过黑盒查询高保真地复制商业机器学习模型。潘菲洛夫团队的贡献，是把这个十年前的经典问题搬到了"加密推理链"这个新的技术设计上，并证明看似解决了旧问题（防止思维链明文泄露）的新设计，本身引入了一个新的、影响范围更大的漏洞。经 web_search 核实，独立研究者早在 2026 年 5、6 月就报告过同类漏洞，OpenAI 当时回应称报告"无法复现"，Anthropic 表示"未见安全含义"；最有力的反驳来自科技评论网站 digg.com 上一篇题为《工程师认可论文本身但拒绝"攻击"框架》的文章，认为潘菲洛夫团队展示的确实是真实的架构缺陷，但把它包装成"攻击"（attack）可能夸大了实际的威胁模型，因为多数场景下需要攻击者本身已经拥有一定的 API 访问权限。

同行视角：
- OpenAI（2026 年 5-6 月对早期同类报告的回应）：认为早期报告"无法复现"，倾向于淡化问题严重性（来源：web_search 综合报道）
- 论文作者团队（Panfilov et al.）：认为这是一个已经在生产环境中被利用、造成真实密钥泄露的严重架构缺陷（来源：论文摘要，经 web_search 核实）
- 主要分歧点：这究竟是一个理论上存在但实际利用门槛较高的"侧信道好奇心"，还是一个已经造成实际损失、需要立即修复的严重漏洞——论文提供的 31.5 万个已解码推理块和真实泄露的密钥，为后一种判断提供了较强证据

对中国商业 / 科技读者的含义：
这条信号的一个值得玩味的侧面是：这一漏洞专门针对"隐藏思维链"的技术路线（如 OpenAI 的 o 系列、部分 Anthropic 模型），而包括 DeepSeek-R1 在内的多个中国开源推理模型，一直以来选择的是"公开完整思维链"的技术路线，本身不存在"加密块被跨模型解密"这个具体攻击面。这与本刊 8 月 11 日报道的"开放权重 vs 集中式 AI"之争形成呼应——今天这条安全信号，从"降低攻击面"这个此前较少被提及的角度，为"公开而非隐藏推理过程"这条技术路线提供了一个新的论据，但这一推论为分析性判断，[未经权威安全机构证实"公开思维链"整体上比"加密隐藏"更安全，两种路线各自仍有其他维度的安全权衡]。

#### 深挖：米拉诺维奇的"中国城市消费之谜"

事实核实：
经 web_search 核实，该文确实发布于米拉诺维奇本人的 Substack（branko2f7.substack.com），核心数据是：2018-2022 年中国城镇实际人均收入增长约 17%，但城镇实际消费下降约 16%；同期农村消费增长约 50%，城乡消费差距从 2.7 倍收窄到 1.5 倍；城镇最富 1% 群体的 2022 年消费水平比疫情前峰值低约 20%，是 2015 年以来的最低点；这一群体在 2018 年的消费约占中国 GDP 的 10-11%。文章明确提出的解释方向是"城镇富裕阶层主动选择少消费、多储蓄"，而非官方常见的"社会保障不足"叙事。

思想溯源：
"中国居民储蓄率过高、消费不足"本身不是一个新话题——国际货币基金组织（IMF）与世界银行的多份报告长期将其归因于社会保障网覆盖不足（尤其是养老、医疗、失业保障），导致居民（尤其是中低收入群体）出于预防性动机被迫多存钱、少消费；这是目前政策圈和学术界的主流解释框架，其政策含义通常指向"应加强社保覆盖"。米拉诺维奇这篇文章的独特之处，在于他把分析焦点从"整体居民储蓄率"收窄到"城镇最富 1% 的具体储蓄行为"——如果连本不需要为医疗、养老发愁的富裕阶层也在主动压缩消费、增加储蓄，那么"社保不足导致预防性储蓄"这个主流解释框架就不足以覆盖全部现象，需要引入精英群体特有的储蓄动机（资本外流顾虑、金融产品变化、人口老龄化等）作为补充。这一视角与米拉诺维奇本人此前提出的"同富阶层"（homoploutia）概念一脉相承——经 web_search 核实，该概念指同一批人同时是资本收入和劳动收入两方面的高收入者，在中国城镇人口中约占最富的 5%；不过需要说明的是，这篇具体文章本身[经 web_search 核实未直接使用"homoploutia"一词，是笔者基于其既有研究框架做出的关联判断]。最有力的潜在反驳，来自主流的社保覆盖不足解释框架本身——如果城镇富裕群体的储蓄行为主要是对更广泛社会不确定性（如整体经济前景、房地产市场）的理性反应，而非"这一群体特有"的行为，那么米拉诺维奇的"精英特殊储蓄行为"论就可能只是"全民预防性储蓄"这个更大现象在富裕人群身上的自然延伸，而非一个需要单独解释的新现象。

同行视角：
- 布兰科·米拉诺维奇（纽约市立大学 Stone Center 高级研究员）：中国城镇消费低迷的核心驱动是富裕阶层主动的储蓄选择，而非社保不足（来源：作者 Substack 原文）
- IMF / 世界银行（长期政策研究立场）：中国居民高储蓄率的主因是社会保障网覆盖不足，尤其是养老、医疗保障缺口，导致居民广泛存在预防性储蓄动机（来源：IMF《Reforms to Reduce China's High Household Savings》工作论文，经 web_search 核实）
- 主要分歧点：储蓄行为的主体究竟是"因保障不足而被迫自保的广大居民"，还是"本不缺保障、却依然选择少花钱的城镇精英"——如果米拉诺维奇的观察成立，意味着仅靠扩大社保覆盖可能无法解决城镇消费不振问题，因为最富裕的那部分消费潜力大户，压缩消费的动机本就与社保无关

对中国商业 / 科技读者的含义：
如果米拉诺维奇的判断成立，对面向中国市场做消费预测的企业和投资人有一个具体的方法论提示：与其只盯着"社保改革进度"这类宏观政策变量来判断消费复苏节奏，不如更细致地追踪城镇最富裕人群的具体储蓄行为和资产配置变化（如高端消费数据、财富管理产品流向、移民与资产配置动向），因为这部分人群贡献了不成比例的消费权重，他们的行为逻辑可能独立于、甚至背离整体社保政策的改善节奏。
